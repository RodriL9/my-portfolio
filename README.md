# Rodrigo Leites-Mena — Personal Portfolio

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS. Features an AI chatbot assistant powered by OpenAI, a working contact form via Resend, and a showcase of my projects.

## Tech Stack

Next.js · TypeScript · React · Tailwind CSS · OpenAI API · Resend API · Vercel

## Running Locally

```bash
npm install
npm run dev
```

Add a `.env.local` file with your `OPENAI_API_KEY` and `RESEND_API_KEY`.
